# GDMaestro

GDMaestro is an MCP server that lets an AI agent build, run, play, and test
Godot games.

This repository is the **public issue tracker** for GDMaestro. It contains no
source code. Use it to report bugs, request features, and see what is already
known.

## Filing an issue

Search the [existing issues](../../issues) first. If yours is new, open one
and include:

- the output of `gdmaestro -version`
- your OS and Godot version
- your MCP client (Claude Code, Cursor, ...) and how GDMaestro is registered
- what you did, what you expected, and what happened, with the exact error
  text

A small project or a short list of the tool calls that reproduce the problem
helps a lot.

## Security

Please **don't** report security vulnerabilities in a public issue. Use
GitHub's private reporting instead: **Security → Report a vulnerability** on
this repository.
